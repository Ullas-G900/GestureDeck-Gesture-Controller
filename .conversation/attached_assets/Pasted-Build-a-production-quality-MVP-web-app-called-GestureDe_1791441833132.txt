Build a production-quality MVP web app called "GestureDeck": a touch-free Hand Gesture Controller for the "Zero One Hackathon, Problem 02: Hand Gesture Controller" (Computer Vision + Human-Computer Interaction).

## Goal
Real-time hand-gesture recognition from the webcam that controls a real application. Pipeline: Camera -> 21 hand landmarks -> Classifier -> Command -> Action. Show this pipeline live in the UI.

## Tech stack (no paid keys, runs fully client-side)
- Vite + React + TypeScript + Tailwind CSS
- @mediapipe/tasks-vision (HandLandmarker, GPU delegate, fallback CPU, numHands=1, load the model from the official MediaPipe CDN)
- Small Node/Express server only for WebSocket relay to hardware (Level 3) and serving the built app
- Must work on Replit's HTTPS preview (getUserMedia requires HTTPS). Bind to 0.0.0.0 and use the PORT env var.

## Layout (dark, modern UI, navy/blue glassmorphism, responsive)
1. Header: "GestureDeck", status chips (Camera, Model loaded, FPS).
2. Left panel: mirrored webcam feed with canvas overlay drawing the 21 landmarks and skeleton, plus a large badge showing the current gesture and confidence.
3. Pipeline strip under the video: Camera -> Landmarks -> Classifier -> Command -> Action. Each box lights up as data flows through it, showing the live gesture name and command.
4. Right panel with tabs: 
   - "Demo App": the controlled application (below)
   - "Gesture Map": table of gesture -> command, editable (remap any gesture to any command)
   - "Train": custom gesture training (Level 2)
   - "Hardware": device connection and virtual devices (Level 3)
   - "Log": timestamped event log of recognized commands
5. Onboarding modal: camera permission explanation, quick gesture cheat sheet with icons.

## Level 1, Minimum (must be flawless)
Rule-based classifier using landmark geometry (no ML needed). Recognize at least 6 static gestures:
- Open Palm -> Pause
- Thumbs Up -> Start / Play
- Point Left (index extended, others curled, pointing left) -> Previous
- Point Right -> Next
- Closed Fist -> Stop
- Victory / Peace (index+middle) -> Volume up or Mute (configurable)
Implementation notes:
- Determine finger extended/curled using tip-to-wrist distance versus PIP/MCP joint distance, normalized by hand size (wrist to middle MCP), so it works at any distance and rotation.
- Handle thumb separately (use thumb tip vs IP/MCP along the palm axis).
- Handle webcam mirroring and handedness correctly so "left" and "right" match what the user sees.
- Reliability layer: require the same gesture for N consecutive frames (~6-8) before firing, apply a cooldown (~800 ms) per command, ignore "unknown/transition" frames, smooth landmarks with an exponential moving average. Expose these as sliders in a Settings drawer (hold frames, cooldown, confidence threshold).
- Show a progress ring on the badge while a gesture is being "held to confirm".

## Demo App (what the gestures actually control)
Build two real controllable apps in the Demo tab, switchable via a toggle:
1. Media Player: plays a few royalty-free audio tracks (generate with Web Audio API oscillators or use bundled/CDN royalty-free files) with a playlist, play/pause, stop, next/previous, volume, and an animated visualizer. 
2. Presentation Viewer: a 6-slide in-app deck (about the project), where Next/Previous change slides, Start enters fullscreen, Stop exits it.
Every command must trigger a visible on-screen action with a toast ("Next track" etc.).
Also provide a "Practice Mode" where the user is asked to perform each gesture and gets a checkmark when recognized, as a quick calibration/demo.

## Level 2, Advanced
- Dynamic gestures: track the index fingertip (or palm center) over a sliding window of ~15 frames. Detect Swipe Left, Swipe Right, Swipe Up, Swipe Down (velocity + displacement thresholds), and Circle (clockwise / counter-clockwise, using accumulated angle around the centroid). Map swipes to Next/Previous/volume, circle to Seek or Rotate.
- Custom gesture training ("Train" tab): user names a new gesture, captures ~30-50 samples via a "Record" button (with countdown), landmarks are normalized (translate to wrist, scale by hand size, flatten to 63 values). Classify with k-Nearest-Neighbors (k=5) with a distance threshold, running in-browser. Save to localStorage, allow delete/re-train, and let users map custom gestures to any command. Export/import gestures as JSON.



## Quality requirements
- Performance: >=24 FPS on a laptop; use requestAnimationFrame with detectForVideo, avoid React re-renders per frame (use refs + canvas for the overlay, and throttle state updates to gesture changes).
- Robust error states: camera denied, no camera, model failed to load, low light warning, "no hand detected" hint.
- Accessibility: keyboard fallback shortcuts for every command, ARIA labels, high contrast.
- Clean architecture: /src/vision (handLandmarker.ts, features.ts, staticClassifier.ts, dynamicClassifier.ts, knn.ts), /src/commands (commandBus.ts), /src/apps (MediaPlayer, Slides, VirtualDevices), /src/components, /server.
- A single command bus (pub/sub) so classifier output -> command -> any app/device subscriber, which makes adding new controllables trivial.
- Unit tests for the geometry helpers and the swipe/circle detectors with synthetic landmark data.
- README.md with setup, gesture cheat sheet, architecture diagram (ASCII), real-world use cases (hygiene-critical settings like hospitals/operating rooms and kitchens, accessibility for motor-impaired users, smart-home/IoT, classroom presentations, gaming), limitations, and future work.

## Deliverables
Fully working app running in the Replit preview with no manual steps beyond allowing camera access. Start by scaffolding the project, then implement Level 1 end-to-end and verify it before building Levels 2 and 3. Seed the app with sensible defaults so the demo works immediately on first load.
